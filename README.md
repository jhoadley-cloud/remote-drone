# Remote Drone

Pixhawk-based autonomous/RC drone project.

This repository is separate from `remote-car`. It contains only drone-specific planning, shopping, prototyping, configuration, and future software.

## Current status

The aircraft architecture is not selected yet. Do not purchase motors, propellers, ESCs, or a frame until the airframe type, target all-up weight, payload, and desired endurance are defined.

## Repository structure

- `parts/SHOPPING_LIST.md` — drone purchases and design decisions
- `parts/OWNED_INVENTORY.md` — owned drone-relevant and shared hardware
- `prototypes/3D_PRINTING.md` — printable references and custom CAD queue

## Related project

The ground rover project is maintained separately in `jhoadley-cloud/remote-car`.
